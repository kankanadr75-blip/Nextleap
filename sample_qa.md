## What these demonstrate

- Every answered reply carries exactly one `Source:` line and the
  `Last updated from sources:` footer. The model is asked only for a chunk
  id; the link is re-derived from our own metadata, so a fabricated
  citation cannot become a real one.
- Refusals are authored copy rather than model output, so they are
  byte-identical on every run and contain no percentages (FR-6).
- The PII reply has no `Source:` line - there is nothing to cite - and none
  of the message is echoed back, logged or stored.
- `ticker symbol` is refused even though the scheme name appears in the
  query and retrieval does return a nearby chunk. The attribute is simply
  not in the corpus, and no distance threshold can catch that, so it is
  handled as a guard rather than as a similarity cutoff.
